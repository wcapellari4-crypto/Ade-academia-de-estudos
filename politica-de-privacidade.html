1. Dados coletados

Para criar uma conta na ADE, o usuário poderá informar nome, telefone e e-mail.

2. Como usamos os dados

Esses dados são utilizados para criar e gerenciar a conta do usuário no aplicativo.

3. Armazenamento

Na versão atual do aplicativo, os dados da conta são armazenados localmente no dispositivo do usuário e não são enviados para servidores externos.

Na versão atual, a ADE não vende, aluga ou compartilha esses dados pessoais com terceiros.

5. Exclusão dos dados

O usuário pode excluir sua conta e os dados armazenados no dispositivo através da opção de exclusão disponível no aplicativo.

6. Segurança

Recomendamos que o usuário mantenha seu dispositivo protegido por senha ou outro mecanismo de segurança.

7. Direitos do usuário

O usuário pode solicitar informações, correção ou exclusão de seus dados, conforme a legislação aplicável.
